Local modifications:
- neural/backend.h: remove the unused model-loader include. Backend is implemented
  by dlshogi; no upstream model loader, NN encoder, backend or cache wrapper links.
- search/classic/node.h: widen edge count to uint16_t, remove protobuf/model
  includes, assert the compact four-byte shogi Edge layout. Node stays 64 bytes.
- search/classic/node.cc: remove model includes; parse starting positions and
  moves through the shogi history adapter.
- search/classic/search.h: replace 256-entry workspaces with kMaxLegalMoves,
  remove Syzygy include, add locked snapshot and path-based proof hooks.
- search/classic/search.cc: exclude tablebase probing; delegate leaf rules to
  cppshogi; select independent black/white draw scores; expose scalar root Q
  and decisive terminal classification from WL (not a biased draw Q);
  apply external proofs to visited nodes and propagate bounds under the node
  lock without waiting for in-flight visits or correcting past visit averages.
  Unvisited siblings keep unknown bounds until their first backup publishes
  the expansion; proof propagation does not read their pending terminal fields.
  Already-terminal ancestors retain their proof when a delayed descendant proof
  arrives. Leaf terminal publication also takes the node lock because a loss
  clears the incoming policy edge, which other workers can already read.
  Generate legal moves once per leaf and pass emptiness to the rule adapter;
  only build final move statistics when VerboseMoveStats is enabled. The latter
  omits default logfile-only statistics, whose histories have no NN cache
  implementation in this integration; explicit verbose statistics are retained.
- search/classic/stoppers/timemgr.h: expose scalar edge evaluations alongside
  edge visits for dlshogi's time-extension decision.
